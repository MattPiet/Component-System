## How to run

- Set the running mode to `Debug | x64`
- If you have issues with environment variables, edit your run configuration to have the following environment values:
  ```PATH=%PATH%;$(ProjectDir)GameDev\OpenGL\dll\64;$(ProjectDir)GameDev\SDL3\dll\64;$(ProjectDir)GameDev\assimp\dll```
